# Canonical Incident on Titan crew portraits

These four portraits are the approved, immutable visual identities for the recurring IOTI crew:

- `viktor.webp` — Viktor, Chief Engineer
- `mara.webp` — Mara, Captain
- `emile.webp` — Émile, Medical Officer
- `aida.webp` — Aida, Science Exobiologist

They are optimized WebP derivatives of the approved character cards supplied by Thomas Judes.

Do not regenerate, reinterpret, replace, or alter these characters without an explicit decision from Thomas. New missions must reuse the relevant canonical portrait.
