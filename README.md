# Confluence of Minds

Confluence of Minds is an independent creative and experimental studio spanning interactive fiction, web experiences, narrative projects and AI-assisted product experiments.

Public site: https://confluenceofminds.com/

## Selected projects

- **Incident on Titan**: interactive web-game / mission experience maintained in this repository under `titan/`
- **Authentiques Victimes**: long-form narrative project with a dedicated web presentation under `authentiques-victimes/`
- **Shattered Dragons: Enigma**: interactive point-and-click narrative experience maintained in its own repository
- **FICTURN**: chat-native short-fiction library with an MCP-powered inline reader, maintained in its own repository

The studio is also used to publish and test additional narrative, interactive and product experiments as they reach a sufficiently mature state.

## Production source of truth: Incident on Titan

The live game is maintained directly in:

`titan/`

Every approved change to `titan/` on `main` is published through the GitHub Pages site at:

`https://confluenceofminds.com/titan/`

The former synchronization workflow and the six-hour copy process have been removed. Do not restore an automated copy from `thomasjudes-del/incident-on-titan`.

For Incident on Titan development, this repository and the `titan/` directory are the single source of truth.

## Why this repository matters

It is both a production website and a working collection of shipped creative experiments. The projects combine writing, world-building, interaction design, web implementation, iterative testing and deployment rather than stopping at static concepts.
