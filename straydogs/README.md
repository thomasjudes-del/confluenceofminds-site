# Confluence of Minds - Straydogs Collective

Static English founding-cohort landing at https://confluenceofminds.com/straydogs/.

- This directory is standalone: no root-site CSS, logo or artwork dependencies.
- No JavaScript, backend, analytics, account creation or form submission.
- Application links open a draft in the visitor’s email app, addressed to thomas@confluenceofminds.com.
- Fonts are self-hosted subsets of Nunito Sans and Outfit, licensed under SIL OFL 1.1; see assets/OFL-NunitoSans.txt and assets/OFL-Outfit.txt.
- The illustrations are original SVG from the approved independent visual mockup. They do not depict existing members or collaborations.
- Publishing uses the existing repository’s GitHub Pages flow. No Worker or Raluva deployment is needed.
