# Confluence of Minds - Straydogs Collective

Static English landing at https://confluenceofminds.com/straydogs/.

A happy animated pack introduces the offer. Three original illustrated scenes explain discovery, voluntary recommendation and collaboration, repeating the story beats used in the launch film. Motion pauses outside the viewport or when the page is hidden. Reduced-motion and no-JavaScript visitors receive complete static compositions. Self-hosted fonts and original SVG artwork; no tracking, backend, forms, accounts or automatic submission. The owner-approved email CTA opens the visitor’s mail app.

The English and French CoM homepages include a linked, silent animated project tile, using the same dog poses as the film. Its scoped viewport controller respects reduced-motion and page visibility without changing other project tiles. Publication uses the existing GitHub Pages flow only.
