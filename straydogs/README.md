# Confluence of Minds - Straydogs Collective

Static English landing at https://confluenceofminds.com/straydogs/.

A pack-led visual hero explains the offer and links to the email introduction. Three original illustrated scenes explain discovery, voluntary recommendation and collaboration. Motion plays once on entering a scene and settles within 4.8 seconds. Reduced-motion and no-JavaScript visitors receive the complete static composition. Self-hosted fonts and original SVG artwork; no tracking, backend, forms, accounts or automatic submission. The owner-approved email CTA opens the visitor’s mail app. Publication uses the existing GitHub Pages flow only.
