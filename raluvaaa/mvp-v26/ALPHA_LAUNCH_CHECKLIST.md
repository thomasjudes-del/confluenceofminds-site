# RALUVAAA V26 - Private alpha launch checklist

## Product gate

- Keep the V03 visual reference locked.
- Use the V26 sandbox for review, not the older semantic prototype.
- Verify the three entrusted wishes show distinct countdowns and replace on expiry.
- Verify CREATE -> EVOLVE -> SPLIT -> +BRANCH -> BLOOM / ABANDON on a real wish.
- Verify correction of an accidental branch is distinct from ABANDON.
- Verify lineage focus is understandable without explanation.
- Verify ENCOURAGE is one-per-human-per-wish.
- Verify HELP, branch suggestions and CONNECT remain proposals until consent.
- Verify desktop and mobile with at least one real device each.

## Private alpha scope

Before shared persistence exists, use the sandbox for product review and moderated demos only. Do not imply that HELP / CONNECT / notifications work between independent real users yet.

For a true private alpha with several real people, the minimum infrastructure is:

1. lightweight identity;
2. shared wish/event persistence;
3. persisted proposals and notification state;
4. permission checks enforcing wisher sovereignty;
5. basic report/moderation and anti-abuse protection.

## Recruitment sequence

- Wave 0: 5-10 people, direct observation and rapid feedback.
- Wave 1: 15-25 people, minimal explanation, measure spontaneous comprehension.
- Wave 2: 30-50 people only after real cross-user persistence works reliably.

## What to measure first

- visitor -> real wish created;
- return to own wish;
- EVOLVE / SPLIT / BLOOM / ABANDON;
- entrusted wish opened and acted on;
- ENCOURAGE;
- HELP proposed / accepted;
- CONNECT proposed / accepted;
- share -> new visitor;
- qualitative answer: did RALUVAAA make you want to do something about your wish?
