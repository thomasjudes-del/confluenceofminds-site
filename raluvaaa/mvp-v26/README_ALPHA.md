# RALUVAAA V26 alpha sandbox

This directory is the current manual-product pre-alpha sandbox.

- Visual language: locked historical V03 baseline.
- Semantic model: wish lineage generated from meaningful wish events.
- Human sovereignty: helpers propose; wishers decide structural changes and Bloom/Abandon.
- No LLM or MCP in this MVP.
- A/B mode is local QA, not a shared-backend multi-user implementation.
