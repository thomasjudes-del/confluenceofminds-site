# Do not promote before

Do not replace the official `/raluvaaa/` route with this sandbox merely because the automated suite is green.

Before promotion, require:

- Thomas manual acceptance of desktop and mobile navigation;
- clear decision whether the first external test is a moderated prototype test or a true multi-user alpha;
- if true multi-user: shared persistence + lightweight identity + cross-device proposal/notification consent;
- no regression of the locked V03 visual reference.
